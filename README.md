# Lottery Simulator

A browser-based lottery simulator for drawing 6 unique numbers from 1 through 40.

## Open

Open `index.html` in a browser.

## Features

- Pick your own six-number ticket
- Quick-pick a random ticket
- Generate lucky numbers and apply them to your ticket
- Run a single draw
- Simulate up to 100,000 draws at once
- Track match counts, best match, jackpots, and recent draw history
